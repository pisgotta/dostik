DecisionApp: Генератор случайных решений Описание

DecisionApp — это легковесное кроссплатформенное мобильное приложение, разработанное для помощи в ситуациях, когда сложно сделать выбор. Пользователь вводит список доступных вариантов (каждый с новой строки), а приложение случайным образом выбирает один из них.

Приложение сохраняет введенные данные и последний результат в локальном хранилище. Благодаря реализации жизненного цикла (on_start, on_stop, on_pause), информация не теряется при сворачивании приложения или нехватке оперативной памяти на устройстве.

Возможности Случайный выбор: Генерация непредвзятого результата из списка введенных пользователем вариантов. Персистентность: Автоматическое сохранение введенного текста и последнего выбора в локальный JSON-файл (decision_app.json). Обработка жизненного цикла: Корректная работа с состояниями мобильного приложения (сворачивание, закрытие, возобновление). Валидация ввода: Проверка на наличие достаточного количества вариантов для честного выбора (минимум 2). Обратная связь (UX): Визуальное изменение цвета текста результата (зеленый — успешный выбор, красный — ошибка) и микро-анимация кнопки при нажатии. Адаптивность: Использование относительных единиц (dp, size_hint) для корректного отображения на экранах с разной плотностью пикселей.

Язык Python 3.11 Основной язык разработки. Разметка UI Kivy Language (.kv) — Декларативное описание интерфейса, отделяющее визуальную часть от бизнес-логики. Хранение kivy.storage.dictstore.DictStore — Встроенная обертка Kivy для работы с локальным JSON-хранилищем (сохранение состояния). Логика Стандартная библиотека — Модуль random для генерации случайного выбора. Стиль кода PEP 8 — Стандарт оформления кода (отступы, нейминг, читаемость). Типизация Python Type Hints — Аннотации типов в бизнес-логике для повышения надежности и читаемости.

Установка и запуск Убедитесь, что у вас установлен Python (версии 3.11 или выше). Установите зависимости: pip install kivy Поместите файлы (main.py, decision.kv, decision_logic.py, config.py) в одну папку. Запустите приложение: python main.py
